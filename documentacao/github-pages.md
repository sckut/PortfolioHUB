# 4. GitHub Pages

## Publicação

1. No repositório, acesse **Settings → Pages**.
2. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Escolha a branch **`main`** e a pasta **`/ (root)`** → **Save**.
4. Após 1–2 minutos o site fica disponível em:
   **https://sckut.github.io/PortfolioHUB/**

## Conteúdo do site

- Apresentação pessoal e áreas de interesse
- Cards dos projetos acadêmicos e pessoais (com link para cada README)
- Seção **Documentos**: links para a documentação do repositório
- Seção **Slides**: apresentação em HTML (`apresentacoes/slides.html`)
- Vídeo da apresentação (YouTube) incorporado
- Histórico de versões e contatos

## Tecnologias

HTML5 semântico, CSS3 (variáveis, grid, modo escuro automático) e JavaScript puro — sem dependências externas, o que deixa o site leve e compatível com o GitHub Pages.
