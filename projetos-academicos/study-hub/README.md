# 📘 Study Hub — Projeto Integrador (Bootcamp I)

> Projeto integrador desenvolvido em fases no Bootcamp I do curso de Engenharia de Software (CEUB).

## 📌 Sobre

O **Study Hub** é uma proposta de plataforma para centralizar a organização dos estudos do aluno (materiais, metas e acompanhamento). Na **Fase 1** foram produzidos o documento base do projeto, a arquitetura de pastas no GitHub e um pitch em vídeo de 5 minutos.

## 🎯 Objetivos

- Definir o problema, o público-alvo e a proposta de valor;
- Estruturar o projeto em um repositório organizado;
- Comunicar a ideia de forma clara em um pitch.
