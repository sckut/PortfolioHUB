# ⏱ PontoApp — Registro de Ponto

> Aplicação web simples para funcionários registrarem entrada, saída e intervalos.

## ✅ Funcionalidades

- Registro de entrada, início/fim de intervalo e saída
- Histórico de marcações por funcionário
- Interface responsiva que roda direto no navegador

## ▶️ Como executar

Abra o arquivo `index.html` no navegador — não precisa de instalação.

## 🛠 Tecnologias

HTML · CSS · JavaScript
