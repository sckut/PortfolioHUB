# 🎲 Jogo de Adivinhação em Python

> Jogo de terminal em que o computador sorteia um número e o jogador tenta adivinhar com dicas de "maior" ou "menor".

## 📌 Sobre

Exercício de **Lógica de Programação** para praticar estruturas de repetição, condicionais, validação de entrada e funções. A versão original foi entregue como notebook Jupyter; aqui está a versão em script.

## ▶️ Como executar

```bash
cd projetos-academicos/jogo-adivinhacao-python
python jogo.py
```

Requisito: Python 3.8+ (sem bibliotecas externas).

## 🕹 Exemplo de uso

```text
=== JOGO DE ADIVINHAÇÃO ===
Escolha a dificuldade (1-Fácil, 2-Médio, 3-Difícil): 2
Adivinhe o número entre 1 e 50. Você tem 7 tentativas.
Tentativa 1: 25
📉 O número é MENOR.
...
🎉 Acertou em 4 tentativas!
```

- `while` e `for`
- `if / elif / else`
- `try / except` para validar a entrada
