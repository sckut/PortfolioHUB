# 🎛 Gestão de Eventos — SaaS de Inventário

> Software de gestão para empresas que alugam equipamentos para eventos (som, iluminação, painéis de LED e estruturas).

## 📌 Contexto

Nasceu da minha experiência na operação de uma empresa de eventos em Brasília (2024–2026), onde o controle de equipamentos era um problema diário. A ideia é usar internamente primeiro e depois oferecer como SaaS para outras empresas do setor.

## 🗺 Roadmap por fases

| Fase | Módulo | Status |
|---|---|---|
| 1 | **Inventário** — cadastro de equipamentos, quantidades e situação | 🟡 Em desenvolvimento |
| 2 | Agenda / calendário de eventos | ⚪ Planejado |
| 3 | Logística (saída e retorno de material) | ⚪ Planejado |
| 4 | Multi-tenant (várias empresas) | ⚪ Planejado |

## 🛠 Stack

Next.js · TypeScript · Supabase · Tailwind CSS

## ▶️ Como executar (quando o código estiver publicado)

```bash
npm install
cp .env.example .env.local   # preencher URL e chave pública do Supabase
npm run dev
```
