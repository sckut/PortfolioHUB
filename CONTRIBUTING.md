# Como contribuir

## Branches
- `main` — versão estável, publicada no GitHub Pages
- `develop` — integração das novas funcionalidades
- `feature/<nome>` — cada nova funcionalidade ou projeto

## Commits (Conventional Commits)
| Prefixo | Uso |
|---|---|
| `feat:` | nova funcionalidade |
| `fix:` | correção de erro |
| `docs:` | documentação |
| `style:` | visual/formatação, sem mudar lógica |
| `refactor:` | reorganização de código |
| `chore:` | tarefas de manutenção |

Exemplo: `docs: adiciona README do projeto Mandaká`

## Pull Requests
1. Crie uma branch a partir de `develop`.
2. Faça commits pequenos e descritivos.
3. Abra um PR para `develop` usando o template.
4. Após revisão, `develop` é mesclada em `main` e uma nova tag é criada.
