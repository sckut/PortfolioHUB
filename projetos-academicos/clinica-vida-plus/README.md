# 🏥 Clínica Vida+ — Modelagem de Sistema de Agendamento

> Trabalho de modelagem de software para um sistema de agendamento de consultas médicas.

## 📌 Sobre

O projeto modela o sistema da clínica fictícia **Clínica Vida+**, que precisa organizar o agendamento de consultas entre pacientes, médicos e recepção. O foco foi a **documentação da arquitetura** antes da implementação.

## 📐 Diagramas produzidos

| Diagrama | O que representa |
|---|---|
| **Componentes** | Módulos do sistema (agendamento, cadastro, notificações) e como se comunicam |
| **Fluxo** | Passo a passo do agendamento, da escolha do horário à confirmação |
| **Entidade-Relacionamento (ER)** | Entidades `Paciente`, `Médico`, `Consulta`, `Especialidade` e seus relacionamentos |
| **Arquitetura** | Camadas cliente, aplicação e banco de dados |

> 📎 Coloque o PDF/imagens dos diagramas na pasta `diagramas/` e atualize os links abaixo.

- `diagramas/clinica-vida-plus.pdf`

## 🛠 Conceitos aplicados

UML · Modelagem ER · Arquitetura em camadas · Engenharia de requisitos

## 🧠 Aprendizados

Traduzir regras de negócio em modelos visuais e pensar na estrutura de dados antes de programar.
