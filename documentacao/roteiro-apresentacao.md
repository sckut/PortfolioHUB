# 6. Roteiro da Apresentação (YouTube — 5 minutos)

Use os slides em [`apresentacoes/slides.html`](../apresentacoes/slides.html) e grave a tela (OBS Studio, Loom ou gravador do Windows `Win + G`). Publique no YouTube como **Não listado** ou **Público**.

| Tempo | Slide | O que falar / mostrar |
|---|---|---|
| 0:00–0:30 | 1. Abertura | Nome, curso (Engenharia de Software — CEUB) e objetivo: "um repositório que funciona como meu portfólio profissional". |
| 0:30–1:15 | 2. Planejamento | As seções (acadêmicos, pessoais, documentação, apresentações) e a árvore de pastas. Mostre o repositório no GitHub. |
| 1:15–2:15 | 3. Versionamento | `git log --oneline --graph --all`; tags `v1.0.0` e `v1.1.0`; branches main/develop/feature; Conventional Commits. Mostre a aba **Tags/Releases**. |
| 2:15–3:15 | 4. Projetos | Abra 2–3 READMEs: Mandaká, Gestão de Eventos, Clínica Vida+. Destaque o padrão de documentação. |
| 3:15–4:15 | 5. GitHub Pages | Navegue pelo site: projetos, documentos, slides, modo escuro, versão mobile. |
| 4:15–4:45 | 6. LinkedIn | Mostre o projeto na seção Projetos e o link em Destaques. |
| 4:45–5:00 | 7. Encerramento | Próximos passos e agradecimento. Links na descrição do vídeo. |
