# 5. Compartilhamento e Integração com o LinkedIn

## Tornar o repositório público

**Settings → General → Danger Zone → Change visibility → Public.**
Link de compartilhamento: `https://github.com/sckut/PortfolioHUB`

## Adicionar ao LinkedIn

### a) Seção "Projetos"
Perfil → **Adicionar seção → Recomendado → Adicionar projetos**

| Campo | Preenchimento |
|---|---|
| Nome | PortfolioHUB — Portfólio de Projetos |
| Descrição | (texto abaixo) |
| Habilidades | Git, GitHub, HTML, CSS, JavaScript, Documentação técnica |
| Associado a | CEUB — Engenharia de Software |
| Mídia / Link | `https://sckut.github.io/PortfolioHUB/` |

**Descrição sugerida:**
> Repositório central do meu portfólio, com projetos acadêmicos (Engenharia de Software — CEUB) e pessoais. Versionado com Git (SemVer + Conventional Commits, fluxo main/develop/feature) e publicado com GitHub Pages. Inclui sistema de pedidos para restaurantes, SaaS de gestão de equipamentos para eventos, modelagem de sistema de agendamento médico e mais.

### b) Seção "Em destaque" (Featured)
Perfil → **Adicionar seção → Recomendado → Adicionar destaque → Adicionar um link** → cole o link do GitHub Pages.

### c) Informações de contato
**Editar informações de contato → Site** → tipo "Portfólio" → link do GitHub Pages.

### d) Publicação de divulgação (opcional)
> 🚀 Publiquei meu PortfolioHUB! Um repositório com meus projetos acadêmicos e pessoais, versionado com Git e publicado no GitHub Pages. Confira: https://sckut.github.io/PortfolioHUB/
> #Git #GitHub #EngenhariaDeSoftware #CEUB #Portfolio

## No GitHub
Adicione o link do LinkedIn no perfil do GitHub (**Settings → Public profile → Social accounts**) e fixe o repositório (**Customize your pins**).
